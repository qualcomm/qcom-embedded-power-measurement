# Getting started

Thank you for downloading the QEPM Software Suite. Let's learn more about each of the applications and
tools provided by QEPM.

Here is a summary of the tools that were installed:

- **EPM Scope**: Perform dynamic (real-time) power measurements on the debug board
- **EPM Viewer**: Analyze, zoom in/out and export static power measurement data
- **Embedded Power Measurement (EPM)**: Collect static power measurement data from the debug board
- **EPM Configuration Editor**: Create and edit EPM configuration power files
- **BugWriter**: Application to create bug reports
- **Command-line utilities**: EPMDump, SCLDump, EPMCLI, UDASCLI, PSOCProgrammer

For issues or feature requests, open a GitHub issue at
https://github.com/qualcomm/qcom-embedded-power-measurement/issues.
